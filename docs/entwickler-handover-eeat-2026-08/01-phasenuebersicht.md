```
Phase 0 → 1 Schema/Disclaimer
       → 2 Meta/Index
       → 3 Anamnese-Links
       → 4 Speed/UX
       → 5 Hub-Einstiege → 7 VERF → 9/10 Kindseiten
       → 6 NLS-Sprache
```
